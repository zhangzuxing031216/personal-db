# 图片说明

本目录目前是 **SVG 示意图**，不是真实截图。

| 文件 | 内容 |
|---|---|
| `vault-overview.svg` | Obsidian 布局示意：目录树、属性、双链、反向链接、图谱 |

## 为什么用示意图

- 知识库内容因人而异，真实截图容易泄露私人笔记；
- 示意图能突出“目录怎么分、属性怎么写、链接怎么连”；
- SVG 体积小、可缩放、GitHub 直接渲染。

## 如果你要补真实截图

建议命名：

| 文件名 | 内容 | 打码 |
|---|---|---|
| `shot-01-vault.png` | Obsidian 打开 vault | 侧边栏私人文件名 |
| `shot-02-note.png` | 一条示例笔记 | 私人内容 |
| `shot-03-graph.png` | 图谱视图 | 私人节点名 |
| `shot-04-review.png` | 周回顾模板 | 无 |

规范：

1. 分辨率 ≥1280×720，PNG，单张 <500KB。
2. 必须使用示例笔记或打码；不要暴露真实日记、客户名、证件号。
3. 图中路径要和文档一致，或明确写“示例”。

> 不要用 AI 生成“假截图”冒充真实界面。示意图可以，伪造截图不行。
