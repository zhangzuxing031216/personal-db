# 个人知识库入口

> 先写，再整理。找不到就从这里进。

## 这个库是干什么的

- 记录事实、决策、踩坑、读书/论文素材。
- 可搜索、可链接、可备份。
- 给 AI 一份规则，让它按规则帮忙整理。

## 快速入口

- [[01-inbox]]：先丢进来，每周清。
- [[02-projects]]：有截止日/有产出的事。
- [[03-areas]]：长期责任。
- [[04-resources]]：主题资料。
- [[05-archive]]：完成/失效，保留可搜。

## 最近更新

- [[example-note]]：一条示例笔记，照着写。
- [[example-project]]：一个示例项目页。

## 规则

- 一条笔记一个主题。
- 先搜再写，追加优先。
- 事实标来源，推断标置信度。
- 不写密码、token、证件号、客户隐私。
- 详细规则见 [[AGENTS]]。
