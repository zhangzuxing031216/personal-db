# 示例项目：把库跑起来

## 目标

一周内让个人库“能用”，不追求完美。

## 成功标准

- [ ] 每天往 `01-inbox/` 丢 1 条。
- [ ] 周末清一次收件箱。
- [ ] 有 10 条真实笔记。
- [ ] 有 3 个 `[[链接]]`。
- [ ] 完成一次备份恢复演练。

## 现状

刚建库，只有模板。

## 下一步

- [ ] 写第一条真实笔记。
- [ ] 设置 Obsidian 新笔记默认到 `01-inbox`。
- [ ] 初始化 Git（private）。

## 风险

- 只收藏不整理。
